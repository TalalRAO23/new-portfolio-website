# Backend (coming later)

This folder is empty on purpose. When you're ready, this is where your
Express + MongoDB API can live — for example, an endpoint that receives the
contact form submissions from the frontend and stores them or emails them
to you.

Suggested starting structure when you get to it:

```
backend/
├── server.js
├── routes/
├── controllers/
├── models/
└── .env
```
